# Provenance and licensing

ISyCoFeedback is the canonical product. Danny explicitly authorized merging his owned implementations and publishing their original code under MIT on 2026-10-21. The sources remain in their original working directories; no remote repository was restored or published.

| Operational Trust Pipeline | HEAD 564c1d2cc317f16df069d9978c3717825fdf8cd1, modified local source | Operational contracts, generic acknowledgement policy, durable lifecycle and memory/SQLite backends |

`MIGRATION_MANIFEST.json` records exact SHA-256 values of the source files as copied. A modified working tree is not represented by its HEAD alone. Subsequent edits in the destination are visible in the Git diff; the manifest preserves the import moment rather than claiming to hash every future change.

Source-specific integrations, customer datasets, PDFs, workbooks, credentials, old GUI bundles and contest material were excluded. The resulting package has no external communication channel enabled by default. `RecordingChannel` is an explicitly local fixture channel and proves no external delivery.

The MIT copyright notices remain in LICENSE. Runtime dependencies keep their own licenses. The historical code predates this merger: a version change does not re-date the work. For a hackathon submission, disclose the original project and identify the newly added automation and deployment separately.

Document schemas now use `isycofeedback.documents.*`; the merger does not silently migrate or certify evidence generated by old packages. Command receipts use `isycofeedback.receipt/2`. Existing unsealed command receipts remain historical files and fail the new audit until handled explicitly; do not silently reseal old claims.
